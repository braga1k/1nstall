# 1nstall 3.2.0-review

Public prerelease of the installed-aware library and reviewed Update Center. **Unsigned; isolated publisher-installer and native desktop tests are deferred.** No production-readiness or 9/10 rating is claimed.

- Essentials starting view, remembered library views, descriptions, method/status labels and mouse/F1 app details.
- Exact package identities, asynchronous installed discovery and honest Installed / Not installed / Unknown states.
- Explicitly reviewed exact-version updates, WinGet pin protection, separate 1nstall holds, stop-after-current and freshly checked retries. No unattended updates by default.
- Backward-compatible selection profiles, validated installed-app snapshots and import previews.
- Timestamped per-app history, detailed logs and redacted diagnostics reviewed before saving/sharing.
- Recursive dependencies, failure blocking, safe Windows arguments, process-output handling and state verification.
- Cleanup requires verified removal/ownership and separate consent; registry backups, folder recycling and protected/shared checks remain.

## Downloads and requirements

Use **1nstall.exe** or the **Windows-x64 ZIP**. The source ZIP includes the reviewed source, before/after rendered WPF evidence, tests and documentation. BUILD-INFO.json identifies the exact commit and build inputs; SHA256SUMS.txt covers all downloadable assets except itself. The executable is portable and does not require Python, Zig or the source folder.

Windows x64, Windows PowerShell 5.1 and WPF/.NET Framework are required. Automatic installation requires WinGet. Full inventory and Update Center additionally require PowerShell 7 in its standard Program Files location and Microsoft.WinGet.Client 1.7+. These prerequisites are not installed automatically. Structured WinGet export may confirm some installed identities without them; omissions remain Unknown. Unsupported/ambiguous pin output withholds updates.

Snapshots restore selections, not personal files, app settings, credentials or guaranteed identical versions. Apps outside the catalog are previewed as unavailable/manual. Similar display names cannot authorize package actions or cleanup.

## Evidence and deferred checks

Local Windows build 26100: catalog audit, 66 headless reliability checks, existing WPF smoke suite, manager UI fixtures and standalone executable tests passed. Screenshots and 100/150/200% images are WPF raster renders, not native desktop/DPI proof. No everyday application was used as a disposable fixture.

The attached CI logs report the publication run's headless catalog/reliability checks and packaged self-test. CI does not test an interactive desktop or actual publisher installers.

Deferred: disposable Windows EXE/MSI/Store installation, live upgrade/uninstall, UAC, reboot, cleanup recovery, live Client/pin/localization behavior, native keyboard/accessibility/high contrast and actual OS scaling. Native compositor capture was unavailable in the local session. The alternate Python/Zig builder remains unverified. The build is unsigned; authorized signing setup and the original-code license decision remain owner actions. Third-party Apache/NOTICE attribution is preserved.
