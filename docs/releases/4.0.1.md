# 1nstall 4.0.1

A calmer dark theme and four more apps.

## What's new

- **Neutral dark theme.** The dark appearance is now charcoal grey and looks the same whatever your Windows accent colour is. The accent colours only what is selected or acts: buttons, switches, selected cards and the active page, as it already did in the light theme. Earlier versions tinted the dark panels with the opposite of the accent colour over blue-grey and lavender, and some accent colours clashed with it. The light theme and the monochrome option are unchanged.
- **Four more apps, 329 in all.** AB Download Manager (Files & Downloads), ArtCraft Studio (AI Tools) and T3 Code (Development) install with WinGet. ArtCraft Launcher (Design & Photography), which installs the ArtCraft creative apps, has no WinGet package, so it opens the publisher's download page.

Everything else is 4.0.0: the same engine rules, files and settings.

## Download

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-4.0.1-Windows-x64.zip:** executable, documentation, notices, build information and CI logs.
- **1nstall-4.0.1-source.zip:** exact tracked source bytes corresponding to the build.
- **SHA256SUMS.txt / BUILD-INFO.json:** SHA-256 hashes, source commit and build provenance.

Installations of 3.3 or newer can receive this release through Settings > Automatic updates. Older releases require a manual download.

## Requirements and limits

Windows 10/11 x64 and .NET Framework 4.8/WPF, which Windows includes. Automatic app installation needs WinGet and internet access. The other requirements and limits are those of [4.0.0](https://github.com/braga1k/1nstall/releases/tag/v4.0.0).

The executable is unsigned. Builds are not bit-for-bit reproducible. The new dark theme was looked at with six accent colours on one Windows 11 PC, through a test setting that names the colour without changing Windows; a live change of the Windows accent colour while the app is open was not exercised. The four new apps were checked against their WinGet manifests or official page; installing them was not tested. Not run on Windows 10.
