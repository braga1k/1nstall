# 1nstall 3.6.0

Selection that answers your hand, with elastic switches in Install and Uninstall and smoother native feedback throughout the app.

## What's new

- Replace app selection marks with switches that lean on press, stretch during travel and settle softly. Rapid clicks reverse from the current position.
- Keep selection immediate, native keyboard/UI Automation support and Windows reduced-motion behavior. Installation and removal still require review.
- Fade selection colours and card highlights smoothly; retain equal switch geometry and a permanent edge in both states.
- Give buttons continuous spring feedback and reveal expander content without animating layout height.
- Refresh the README with four current English screenshots and consolidate build/test/release documentation.
- Remove the legacy Python/Zig/C build, obsolete icon exports, old screenshot/log copies and stale status/release documentation. Earlier versions remain in Git tags and Releases.
- Group catalog review/provenance under `docs/catalog/` and run elastic-motion bounds/reversal checks in CI.

## Download

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-3.6.0-Windows-x64.zip:** executable, documentation, notices, build information and CI logs.
- **1nstall-3.6.0-source.zip:** exact tracked source bytes corresponding to the build.
- **SHA256SUMS.txt / BUILD-INFO.json:** SHA-256 hashes, source commit and build provenance.

Existing 3.3 or newer installations can receive this release through Settings > Automatic updates. Older releases require a manual download. Selections and preferences remain compatible.

## Requirements and limits

Windows 10/11 x64, Windows PowerShell 5.1 and .NET Framework 4.8/WPF. Automatic app installation needs WinGet and internet access. Full installed-package awareness additionally uses PowerShell 7 and Microsoft.WinGet.Client 1.7+; otherwise omitted apps remain Unknown.

The executable is unsigned. Live installer/removal, reboot, accessibility, physical DPI and hardware coverage remain bounded. Motion tests do not guarantee GPU smoothness under every workload. Cleanup requires separate review and cannot promise that every leftover was found. Profiles/snapshots restore selections, not personal app data.
