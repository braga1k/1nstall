# 1nstall 3.3.0

Make 1nstall yours with Settings, ten interface languages and automatic app updates. Light, dark and monochrome appearances retain the same gradients, reflections and depth.

## What's changed

- **Settings:** a dedicated page with preferences saved per Windows user. Changing appearance or language preserves app selections.
- **Appearance:** System, Light or Dark; optional Windows accent. Switch accent off for a completely black, white and grey interface, retaining its gradient materials and light effects.
- **Languages:** English, Simplified Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese (Portugal), Indonesian and Urdu. Arabic and Urdu use right-to-left layout; Portuguese is exclusively pt-PT.
- **Automatic 1nstall updates:** checks stable GitHub releases in the background, verifies SHA-256 and executable identity/version, and applies a newer release after the app closes. The previous executable is retained as `1nstall.exe.previous`. A writable app folder is required.
- **Consistent layout:** equal library margins and activity bars ending at the app-card edge.
- **Pointer reflections:** matching moving light in Install, Uninstall and Settings, respecting reduced motion and disabled transparency.

The catalog remains **325 apps, 24 categories and 20 profiles**. This updater updates 1nstall itself; it does not update installed applications.

## Downloads

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-3.3.0-Windows-x64.zip:** app, documentation, notices, build information and test logs.
- **1nstall-3.3.0-source.zip:** source bytes corresponding to the build.
- **SHA256SUMS.txt:** checksums of the release assets.

Existing 3.2 installations need to download 3.3 manually once; 3.2 did not include this updater. Preferences are stored in `%LOCALAPPDATA%\1nstall\settings.json`.

## Validation and current limits

Local packaged smoke and manager suites cover appearance transitions, gradient contrast, monochrome rendering, pointer light, language changes, selection preservation and persistent preferences. Update checks include rejection of corrupt files and replacement of disposable copies with a previous-version backup. Windows CI runs catalog checks, 54 headless regressions, a build and packaged self-test, then verifies all uploaded asset digests before publication. No personal app was installed or removed by these tests.

Requires Windows 10/11 x64, Windows PowerShell 5.1 and WPF/.NET Framework. WinGet is used for automatic installations. The executable is unsigned. Native Desktop Acrylic needs a supported Windows 11 build; other systems use the available fallback. App descriptions, original licence notices and raw diagnostic output keep their source language. Translations still need native-speaker review. Physical DPI, screen readers, other Windows configurations, elevation and restart flows retain the documented coverage limits.
