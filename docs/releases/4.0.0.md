# 1nstall 4.0.0

The same app, rebuilt: the rules now live in a Rust engine and the window no longer runs inside PowerShell. It opens in about a quarter of the time and uses less than half the memory.

## What's new

- Replace the PowerShell host with a native C# window over a Rust engine. The interface, its motion, the 51 languages and the catalog are the ones from 3.6.
- Open faster and use less memory. On the development PC, 3.6.0 was ready in about 2.0 s with a 242 MB peak; 4.0.0 is ready in under 0.5 s with a peak near 115 MB. Your numbers will differ.
- Report an internal engine error in a message and in the session log, and keep the app open.
- Refuse a package identifier or registry path that ends in a line break. 3.6 passed it on to the WinGet command line.
- Stop treating the folder of an uninstaller or icon as an app's install folder during removal. 3.6 could offer that folder for recycling as a linked path.
- Follow uninstaller processes without opening them, so removals that elevate through UAC no longer end in "Access is denied".
- Accept the WinGet source agreements when checking the result of an install you already agreed to, so a new PC no longer reports every install as Unknown.
- Write the removal history through a temporary file, so an interrupted write cannot truncate it.
- List the Rust components of the engine under Licenses & credits.

## What changed for you

- **No opening splash.** It existed to cover the loading time.
- **Installed-package awareness is partial for everyone.** 3.6 could read a complete inventory when PowerShell 7 and Microsoft.WinGet.Client were installed. 4.0 reads `winget export` only: apps it lists are confirmed as installed, and the others stay Unknown. Because absence cannot be proven, **the "Refresh & review installation again" button of a failed install is never offered in this release.**
- 4.0 reads the same files as 3.6 for selections, saved setups, preferences and history.

## Download

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-4.0.0-Windows-x64.zip:** executable, documentation, notices, build information and CI logs.
- **1nstall-4.0.0-source.zip:** exact tracked source bytes corresponding to the build.
- **SHA256SUMS.txt / BUILD-INFO.json:** SHA-256 hashes, source commit and build provenance.

Installations of 3.3 or newer can receive this release through Settings > Automatic updates. Older releases require a manual download.

## Requirements and limits

Windows 10/11 x64 and .NET Framework 4.8/WPF, which Windows includes. Automatic app installation needs WinGet and internet access. Windows PowerShell is still used for one thing: listing Microsoft Store apps on the Uninstall page.

The executable is unsigned. Builds are not bit-for-bit reproducible. 4.0 was compared with 3.6 by an automated oracle on GitHub's Windows Server 2022 and 2025 images and exercised on one Windows 11 PC; it was not run on Windows 10. Real removals were driven through the engine on disposable machines, not through the window. Live installer/removal, reboot, accessibility, physical DPI and hardware coverage remain bounded. Cleanup requires separate review and cannot promise that every leftover was found.
