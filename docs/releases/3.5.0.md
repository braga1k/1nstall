# 1nstall 3.5.0

Removal stays in view from the first publisher dialog to the final result. This release brings a persistent Uninstall queue, more useful disk and registry leftover review, and glass window controls that match the rest of 1nstall.

## What's changed

- Keep Uninstall selections visible as a queue through publisher dialogs, verification, leftover review and inventory refresh, with per-app phases and processed-app progress.
- Wait for observed publisher child processes before verifying removal or starting the next app; preserve stop-after-current behavior and manual/restart outcomes.
- Expand bounded leftover discovery across product folders, AppData, ProgramData and product registry keys, with linked-path/name-match evidence and measured file counts and sizes.
- Add a themed leftover review with separate disk/registry totals, explicit selection and consent, registry backups and folder recycling. Keep the cleanup result visible and celebrate complete success with the whole-window glow.
- Recheck captured removal identities and protect reinstalled/shared apps; distinguish incomplete scans from an empty result. Exclude hidden sparse Store shell-integration packages from the installed-app list.
- Give minimize, maximize/restore, close and dialog dismiss buttons the same rounded glass, reflections and pointer light as the rest of the app.
- Expand all 51 locale packs to 239 interface strings and add queue, process-completion and cleanup UI regression checks.

The catalog remains **325 apps, 24 categories and 20 profiles**. Portuguese remains pt-PT only. The updater updates 1nstall itself, not installed applications.

## Downloads

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-3.5.0-Windows-x64.zip:** app, documentation, notices, build information and CI logs.
- **1nstall-3.5.0-source.zip:** exact source bytes corresponding to the build.
- **SHA256SUMS.txt:** checksums of release assets.

Users on 3.3 or newer can receive this version through Settings > Automatic updates. Preferences remain in `%LOCALAPPDATA%\1nstall\settings.json`.

## Validation and current limits

Local packaged self-test, smoke and manager suites pass, alongside 56 reliability checks, catalog/locale checks and the queue and cleanup WPF suites. Isolated Windows Sandbox testing covered real 7-Zip and Notepad++ EXE removals, retained AppData, product registry keys, backup/restore and recycling/restore. Native fixtures cover delayed child/grandchild completion, cancellation and sequential execution. No personal host applications were removed.

Windows CI builds the committed source, checks the catalog, locales and reliability, runs the packaged self-test, and verifies source-input and uploaded-asset hashes before publication.

Leftover discovery is bounded, and candidates require review and separate consent. Moved-to-Recycle-Bin bytes are not newly freed disk capacity. This does not implement every BCU provider. MSI/Store removal, elevation, actual restarts, Windows 10, physical accessibility/DPI and native translation proofreading need broader coverage. Explorer foreground behavior retains the documented manual-check limitation.

Requires Windows 10/11 x64, Windows PowerShell 5.1 and .NET Framework 4.8/WPF. Automatic catalog installation requires WinGet. The executable is unsigned; native Desktop Acrylic requires a supported Windows 11 build.
