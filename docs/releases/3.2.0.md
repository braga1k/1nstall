# 1nstall 3.2.0

The stable 3.2 release brings the refined library and matching Install/Uninstall workflows, with 325 apps, 24 categories and 20 profiles.

## What's changed

- New centered vector logo and violet-and-sage Windows icon.
- Symmetrical glass sidebars, consistent search and filter controls, clearer categories and smoother text.
- Compact cards with stable sizing; descriptions and installed-state details move into the integrated Details window. Numbers sort first and symbol-prefixed names last.
- Both modes use a Selection panel listing chosen apps with individual remove controls. Clear selection in Uninstall now clears the list checkboxes correctly, including after filtering.
- Matching interactive glass effects and a fixed scrollbar gutter keep selection controls aligned.
- Compiled WPF interface and native helpers, in-process PowerShell, parallel preparation and cached startup profiles retain the existing animations.
- Installed awareness, portable setup snapshots, operation history and reviewed diagnostic exports.
- Essentials and the Update Center removed; Buy me a beer added for optional support.

## Downloads

- **1nstall.exe:** standalone Windows x64 application.
- **1nstall-3.2.0-Windows-x64.zip:** executable, documentation, notices, build information and checks.
- **1nstall-3.2.0-source.zip:** source corresponding to this build.
- **SHA256SUMS.txt:** checksums for the published assets.

Requires Windows 10/11 x64, Windows PowerShell 5.1 and WPF/.NET Framework. Automatic installations use WinGet. The executable is unsigned. Desktop Acrylic uses supported Windows 11 systems; other configurations use opaque surfaces.

## Validation and current limits

Local WPF manager and smoke tests pass, including narrow cards, duplicate app names, filtered selections, Clear selection, scroll alignment and reduced-motion/opaque fallbacks. Windows CI runs catalog, headless reliability and packaged self-tests before publication; its logs and source-input hashes accompany the release. No personal app was installed or removed during these tests.

Startup remains hardware/environment dependent: the final local comparison measured about 3.2 seconds, so 1–2 seconds is not guaranteed. Live publisher installers, Store removal, elevation, restart outcomes, native accessibility and per-monitor DPI need broader end-to-end coverage. Cleanup remains bounded and requires a separate review. Snapshots restore selections, not app data or settings.
