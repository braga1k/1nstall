# 1nstall 3.4.0

A more expressive Windows app manager, from its first frame to a completed queue. The familiar gradient materials now carry coordinated movement throughout the interface, with 51 language choices and clearer installed-app feedback.

## What's changed

- Add coordinated entrances, hover/press feedback, selection motion and a whole-window glow after verified installation/removal success, respecting Windows motion preferences.
- Show a themed opening while the main app loads, sharing its light/dark/accent/monochrome background and native material. Transfer ownership before closing the opening to improve foreground handoff.
- Expand to 51 offline language choices covering national official European languages, Japanese and existing languages. Portuguese remains pt-PT only; native-speaker review remains pending.
- Restore Segoe UI, reserve space for animated controls, enforce a 1040 × 540-DIP minimum window and adapt profile controls to translated labels.
- Dim confirmed installed apps while retaining interaction; remove app-description hover popups and keep Details/F1.
- Center both library scrollbars in matching gutters and fix empty scroll tails across lists and menus.
- Rebuild the README with current English screenshots and correct historical 3.3 screenshots to English.
- Extend appearance, startup, scrolling and locale checks; target .NET Framework 4.8 explicitly for the WPF APIs in use.

The catalog remains **325 apps, 24 categories and 20 profiles**: 277 WinGet entries and 48 guided publisher downloads. The existing updater updates 1nstall itself, not installed applications.

## Downloads

- **1nstall.exe:** standalone Windows x64 app.
- **1nstall-3.4.0-Windows-x64.zip:** app, documentation, notices, build information and CI logs.
- **1nstall-3.4.0-source.zip:** exact source bytes corresponding to the build.
- **SHA256SUMS.txt:** checksums of release assets.

Existing 3.3 users can receive this version through Settings > Automatic updates. Older releases require a manual download. Preferences remain in `%LOCALAPPDATA%\1nstall\settings.json`.

## Validation and current limits

Local packaged self-test, smoke and manager suites pass. Coverage includes 51 locale choices, selection preservation, theme changes, animation safeguards, scrolling endpoints and eight matching opening/main-background combinations. The foreground handoff passes internal ownership/modal-window checks; Windows denied the test fixture foreground access, so actual Explorer double-click behavior still needs manual confirmation. No personal app was installed or removed by these checks.

Windows CI runs catalog and locale validation, 56 headless regressions, build and packaged self-test, then checks source-input hashes and uploaded release digests before publication.

Requires Windows 10/11 x64, Windows PowerShell 5.1 and .NET Framework 4.8/WPF. Automatic catalog installation requires WinGet. The executable is unsigned. Native Desktop Acrylic requires a supported Windows 11 build. Translation proofreading, physical DPI/accessibility and live installer/removal/elevation/restart scenarios retain the documented coverage limits. Startup speed depends on the machine.
